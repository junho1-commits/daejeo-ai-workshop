# 🏫 2026학년도 대저중앙초 전문적학습공동체 AI·디지털 역량강화 연수
### 주제: AI·디지털 기술을 활용한 수업자료 만들기 (안티그래비티 에이전틱 코딩 & 웹앱 배포)

본 저장소는 **대저중앙초등학교 전문적학습공동체** 선생님들을 대상으로, 코딩 경험이 전혀 없어도 구글 **안티그래비티(Antigravity)**를 활용하여 내일 당장 수업에 쓸 수 있는 맞춤형 웹앱(수업용 타이머, 교과 퀴즈, 학급 자리배치기 등)을 직접 제작하고, GitHub & Netlify로 배포하는 과정을 인터랙티브하게 실습할 수 있도록 제작된 웹 기반 프레젠테이션 애플리케이션입니다.

---

## 🌟 주요 특징 및 연수 핵심 내용

1. **5인 멀티 에이전트 협업 체계**
   - **[👑총괄 PM / ✍️내용팀 / 🎨디자인팀 / 🔍검수팀 / 💡컨설턴트팀]**이 협업하여 만든 고품질 슬라이드 구성
   - 슬라이드 상단의 **[에이전트 인사이트]** 버튼으로 각 장표별 에이전트 기획 회의록 확인 가능
2. **Skills & MCP 확장 기능 탑재 (8번 슬라이드)**
   - **Skills(스킬)**: AI에게 쥐어주는 '학급경영/수업자료 업무 바인더' (전문 지식 & 규칙)
   - **MCP(프로토콜)**: AI에게 꽂아주는 '만능 도구 USB 연결잭' (구글 시트 명단 읽기, 실시간 랭킹 DB 연동)
3. **실시간 인터랙티브 체험 도구 내장**
   - 🤖 **Gemini 챗봇 vs Antigravity 에이전트 비교 시뮬레이터** (Slide 5)
   - 🧠 **교육 도메인 지식 퀴즈** (Slide 3)
   - 🛠️ **에러 발생 & AI 자동 복구 시뮬레이터** (Slide 10)
   - 📋 **골든 프롬프트 4단 조립기 & 원클릭 복사기** (Slide 11)
   - 📱 **Netlify URL 실시간 QR코드 생성기 & 팡파레 축하 효과** (Slide 16)
4. **연수 제출용 고화질 PDF 일괄 저장/인쇄 기능**
   - 상단 우측 **`[📄 PDF 저장]`** 버튼 클릭 시 17개 슬라이드 전체가 A4 가로 규격 PDF로 즉시 변환 (단축키: `Ctrl + P`)
5. **발표자 전용 모드 (Presenter Guide)**
   - 강사용 티칭 꿀팁, 교실 비유 가이드, 돌발 질문 대처 스크립트 수록 (단축키 `P`)

## ⌨️ 키보드 단축키 안내

| 키 | 기능 |
| :--- | :--- |
| `→` / `Space` / `PageDown` | 다음 슬라이드로 이동 |
| `←` / `PageUp` | 이전 슬라이드로 이동 |
| `Ctrl + P` | 17개 슬라이드 전체 PDF 인쇄 / 저장 |
| `A` | 5인 에이전트 회의록 서랍 열기/닫기 |
| `P` | 강사용 발표자 노트/꿀팁 모달 열기/닫기 |
| `M` / `ESC` | 전체 17개 슬라이드 목차 맵 열기/닫기 |
| `F` | 전체화면 모드 토글 |
| `Home` / `End` | 첫 번째 / 마지막 슬라이드로 즉시 이동 |
